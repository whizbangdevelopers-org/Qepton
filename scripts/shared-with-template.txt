# `code/` holds six sibling products — Qepton, Qepton-Dev, Qepton-Plugins, Qepton-Plugins-Premium,

# restructured to satisfy a path convention.

# Paths below are written EXACTLY as the archetype writes them. A `code/…` row is package-relative
# and the auditor re-roots it against this repo's derived package root (`code/Qepton-Dev`); a
# `scripts/…` or `.claude/…` row is repo-relative and is used as-is. The derivation reads this
# script's own location, so nothing here declares it — the manifest declares ITSELF, and any
# per-repo directive would show up as a fork of the very file that detects forks.
#

# sides today. Declaring the other 25 would produce a report that is two-thirds warnings on its
# first run, which is a report nobody reads. Add a row when the file genuinely lands here.
#
